# Собранный Хозяин

Ежедневная операционка на телефоне. Не витрина бренда.

Утро: щель, 3 шкалы (тело/голова/дух), одно главное, 3 якоря.
Вечер: закрыть день (главное / что вымотало / переношу / отпускаю).
Ещё: речь, протоколы, фото-трек, справочник, история, экспорт.

Данные в браузере (localStorage + IndexedDB для фото). Добавь на
домашний экран — работает как PWA.

Полное ТЗ: `docs/TZ-v2.md`.
