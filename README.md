# Собранный Хозяин

Интерактивное веб-приложение для управления личным брендом предпринимателя Алексея Познахирина (основатель wellness-проектов **ZIMA** и **LETO** на Пхукете).

---

## Техническое задание (исходное)

### Цель

Создать приложение, которое помогает владельцу **внедрять и жить** личным брендом, а не просто читать документ о нём.

Исходный материал — подробный 20-страничный документ «Личный бренд — Алексей Познахирин» (дата фиксации: 28 июня 2026).

### Главная формула бренда

> Алексей Познахирин — предприниматель-хозяин, который строит пространства, людей и себя через честность, вкус, дисциплину и заботу.

**Ключевая фраза:** «Строю бизнесы, пространства и себя.»

### Что должно быть в приложении

Приложение должно отражать и давать инструменты по всем ключевым блокам документа:

1. **Ядро личности**
   - Текущая реальность vs желаемое состояние
   - Ценности: честь, совесть, слово, справедливость, забота, вкус, служение, ответственность
   - Три архетипа: **Хозяин**, **Наставник**, **Искатель**
   - Манифест

2. **Визуальный код**
   - Цветовая палитра (чёрный, графит, песочный, оливковый и др.)
   - 5 формул повседневной униформы (Хозяин ZIMA, Resort Owner, Переговоры, Вечер, Объект)
   - Часовая лестница и рекомендация по машине (Porsche Cayenne)
   - Фотографические формулы

3. **Речь и публичная манера**
   - Принцип: спокойная сила, короткая мысль, ясная позиция
   - Словарь бренда
   - Что убрать из речи
   - Готовые формулировки (команда, критика, видео)

4. **Управленческий образ**
   - Архетип: добрый, но не мягкий; требовательный, но справедливый
   - Формула постановки задач (5 элементов)
   - 3 уровня реакции на ошибки
   - 5 управленческих границ
   - Мантра: «Я могу понять причину. Но я не могу отменить стандарт.»

5. **Темы контента**
   - Честное предпринимательство
   - Хозяин пространства
   - Мужская зрелость
   - Банная культура и восстановление
   - Жизнь предпринимателя в Таиланде
   - Генератор идей постов/видео

6. **Управление энергией и состоянием**
   - Три вида энергии (физическая, нервная, волевая)
   - Дневная энергетическая система (таймлайн)
   - Главные утечки энергии и правила их закрытия
   - Протоколы восстановления
   - Ежедневная шкала состояния (5 параметров, max 50)
   - Вечернее закрытие дня (5 строк)

7. **Практические инструменты**
   - Сохранение состояния и журнала (localStorage)
   - Генератор задач
   - Генератор контент-идей
   - Справочник с поиском по материалам документа

### Требования к реализации

- Полностью клиентское приложение (работает без сервера)
- Современный тёмный дизайн, спокойный и статусный (соответствует бренду)
- Удобная навигация (боковая панель)
- Данные сохраняются локально в браузере
- Адаптивность
- Чистый код, разделённый на HTML / CSS / JS

## Как запустить

1. Скачай репозиторий или папку `brand-app`
2. Открой `index.html` в любом современном браузере
3. Всё. Никаких установок и серверов не требуется.

Данные (история состояний, журнал закрытий дней) сохраняются в `localStorage` браузера.

## Основные возможности

| Раздел        | Что делает                                      |
|---------------|-------------------------------------------------|
| Дашборд       | Шкала состояния, быстрые действия, Bio          |
| Ядро бренда   | Формула, архетипы, манифест                     |
| Визуальный код| Цвета, формулы одежды, часы, машина             |
| Речь          | Принципы, словарь, примеры                      |
| Управление    | Генератор задач, уровни реакции, границы        |

| Трекер        | История состояний + вечерний журнал             |
| Справочник    | Поиск по ключевым материалам документа          |
